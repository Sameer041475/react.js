# React 2 – React.js Learning Projects

This repository contains my React.js practice projects, built while learning frontend development and improving my React skills.

## 📚 Projects Included

### 1. Delete Comment App
A React application that demonstrates comment management.

**Features:**
- Display a list of comments.
- Add new comments.
- Delete comments individually.
- Update the UI dynamically using React state.
- Generate unique IDs using UUID.

**Concepts Learned:**
- React Components
- Props
- useState Hook
- Event Handling
- List Rendering
- Conditional Rendering
- UUID

### 2. Search Box
A search functionality project that allows users to search and filter items dynamically.

**Features:**
- Search input field.
- Real-time filtering.
- Display matching results.
- Handle empty search results.

**Concepts Learned:**
- Controlled Components
- useState Hook
- onChange Event
- JavaScript filter()
- String Methods
- Dynamic Rendering

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- UUID

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Sameer041475/react.js.git
```

Navigate to React 2:

```bash
cd react.js/react_2
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
